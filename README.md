# hk-social

מכונת פרסום אוטומטית ל-HK: פוסט כל יומיים, בפייסבוק ובאינסטגרם, בשעה 10:00.

- `content/guidelines.md` — מה מותר ואסור לכתוב, השירותים, סוגי הפוסטים.
- `posts/<week>/*.json` — הפוסטים. סטטוס: `pending` → `approved` → `published`.
- `out/*.jpg` — התמונות (נוצרות אוטומטית מ-`template/post.html`).
- `review.html` — עמוד הסקירה לפגישת יום ראשון.

## זרימה
1. עד מוצאי שבת: פוסטים חדשים לשבוע הבא נכנסים ל-`posts/` בסטטוס `pending`. התמונות ועמוד הסקירה נבנים אוטומטית (workflow `render`).
2. יום ראשון 10:00: פגישה, ואז Actions → `approve-week` → שם השבוע (ואופציונלית מזהים לדחייה).
3. כל יום ב-10:00: workflow `publish` מעלה פוסט מאושר שהתאריך שלו הגיע.

## סודות
- `META_TOKEN` — טוקן הדף (Page access token) הקבוע של "חזות קריספין".

## ממומן (תשתית מוכנה, לא פעיל)
- חשבון מודעות: "HK", act_1886192278456348, בבעלות תיק העסק "חזות קריספין". מקושר לאפליקציית Meta "HK Social Publisher".
- לאפליקציה נוסף השימוש Marketing API (ads_management, ads_read ב-Ready for testing).
- כדי שהמכונה תנהל קמפיינים צריך להנפיק את META_TOKEN מחדש עם ההרשאות האלה. עד אז אין שום פעולה ממומנת.
- כלל: המכונה לא נוגעת בקמפיינים קיימים; רק בקמפיין משלה, אחרי אישור בפגישת יום ראשון.



## ממומן — איך זה עובד מ-27.09
- `ads/plans/*.json` — כל שינוי בחשבון המודעות הוא תוכנית. תוכנית עם `"approved": true` מופעלת לבד ב-push (`ads-apply.yml`); הבוט כותב חזרה `applied[]`. ריצה חוזרת מדלגת על מה שכבר בוצע וממחזרת קמפיין/קבוצה/מודעה שכבר נוצרו.
- `ads/limits.json` — תקרת תקציב יומי כולל. `ads_apply.py` מחשב את הסך אחרי התוכנית ומסרב (`blocked`) אם חוצים. משנים רק ידנית.
- למה push ולא לחיצה: מנגנון ההרשאות של קלוד חוסם לחיצה על "Run workflow" לפעולות שמזיזות כסף; אישור של אייל בצ'אט → סימון approved → push.
- מגבלות של אפליקציה במצב פיתוח (HK Social Publisher): אין `adimages`, ואי אפשר ליצור פוסט-מודעה חדש (1885183). לכן מודעה = קידום פוסט שכבר בדף. פוסט עם `"dark": true` מתפרסם כלא-מפורסם (לא בפיד) בדיוק בשביל זה; מזהה התמונה שחוזר מומר ל-`PAGE_POSTID`.
- Advantage+ audience מסרב לגיל מקסימלי; הסקריפט נופל לקהל רגיל עם `advantage_audience: 0` (הדגל חייב להופיע).
- פעולות: `set_adset_budget` (עם `adset_name` → רק אותה קבוצה), `create_campaign`, `revive` (קמפיין ישן: קבוצה אחת + מודעות בשם, השאר מושהה), `add_ads`, `pause_ads`.
- וידאו: `videos.yml` מושך את כל הסרטונים מ-Meta (`content/videos.json`, `video/*.mp4`, מקוריים בלבד). פוסט עם `"video": "<id>"` מתפרסם כסרטון בדף + ריל באינסטגרם. ה-API מחזיר רינדור מוקטן (רובם 360p) — להחליף בקבצים מקוריים כשיש.
