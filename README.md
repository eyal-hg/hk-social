# hk-social

מכונת פרסום אוטומטית ל-HK: פוסט כל יומיים, בפייסבוק ובאינסטגרם, בשעה 10:00.

- `content/guidelines.md` — מה מותר ואסור לכתוב, השירותים, סוגי הפוסטים.
- `posts/<week>/*.json` — הפוסטים. סטטוס: `pending` → `approved` → `published`.
- `out/*.jpg` — התמונות (נוצרות אוטומטית מ-`template/post.html`).
- `review.html` — עמוד הסקירה לפגישת יום ראשון.

## זרימה
1. עד מוצאי שבת: פוסטים חדשים לשבוע הבא נכנסים ל-`posts/` בסטטוס `pending`. התמונות ועמוד הסקירה נבנים אוטומטית (workflow `render`).
2. יום ראשון 10:00: פגישה, ואז Actions → `approve-week` → שם השבוע (ואופציונלית מזהים לדחייה).
3. כל יום ב-10:00: workflow `publish` מעלה פוסט מאושר שהתאריך שלו הגיע.

## סודות
- `META_TOKEN` — טוקן הדף (Page access token) הקבוע של "חזות קריספין".
